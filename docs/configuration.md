# Configuration

Run `npm run setup` once. It creates an ignored `.local/config.json` and refuses to overwrite it. No environment file is automatically loaded. Unknown configuration fields are rejected, including removed storage and maintenance settings. Empty configuration cannot activate an external storage fallback.

| Setting | Default / meaning |
| --- | --- |
| host | 127.0.0.1; 0.0.0.0 requires explicit allowedHosts |
| port | 43170, restricted to 43000–43999 |
| adminPort | 43171, distinct; listener always 127.0.0.1 |
| browserKey | Random 32-byte hex capability generated by setup; required |
| workerKey | Separately generated 32-byte hex enrollment key; missing/empty disables enrollment and Worker traffic |
| allowedHosts | 127.0.0.1 and localhost; exact hostnames permitted in Host with the configured port |
| server | Worker target, default local Server URL; HTTP, no credentials/query/fragment, same dedicated port range |

Runtime data is stored next to the chosen configuration file under runtime/. Clients cannot choose storage roots through API payloads. Per-item Worker workspaces have fresh random names. No automatic retention policy runs for persistent workspaces. Stop all processes before backing up or removing that instance's files.

The default demo makes no external runtime requests. LAN use is opt-in, intended only for an already trusted network and not separately validated in this candidate. HTTP transmits data and keys without TLS. Never forward these ports to the internet. A remote Worker needs a local config with the correct Server URL and Worker enrollment key; it does not need to know the Server browser key. A locally generated browserKey in its config is unused by the Worker.

Rotate browser/Worker keys in the stopped Server configuration and restart it and its Workers. Do not paste keys into issue reports. A trusted machine holding an enrollment key can register new Worker identities; process sessions prevent accidental identity collisions and stale execution writes, not malicious administrators of enrolled machines.
