# Community development boundaries

This tree is the independent local community edition. Use only synthetic fixtures and its dedicated ports. Never introduce private tool adapters, deployment automation, internal endpoints, secrets or original repository history.

Use Node 22.23.2. Check with npm run check, npm test, npm run build and npm run demo:smoke. Builds target build/. Runtime data remains in ignored local directories. Windows 11 was verified using non-elevated processes under an Administrators-group account; a pure standard-user account remains unverified and is a known limitation, not a v0.1 release blocker. Do not claim additional account or platform acceptance without evidence. Publication requires explicit user authorization and successful checks.
