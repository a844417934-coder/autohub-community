# Community development boundaries

This tree is the independent local community edition. Use only synthetic fixtures and its dedicated ports. Never introduce private tool adapters, deployment automation, internal endpoints, secrets or original repository history.

Use Node 22.23.2. Check with npm run check, npm test, npm run build and npm run demo:smoke. Builds target build/. Runtime data remains in ignored local directories. Do not claim clean standard-user Windows acceptance or hosted CI without actual evidence. Do not publish while any release gate remains pending.
